#Today's Lesson:

Today I learned how to run a Flutter page separately without using main.dart.

#Problem:
I wanted to run materialapp.dart directly on the emulator.

#Solution:
flutter run -t lib/homepage.dart

This command runs the selected Dart file directly on the emulator.
